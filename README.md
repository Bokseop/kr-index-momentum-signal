## 🎯 핵심 전략 규칙 (해법 1)

- **투자 대상 (딱 3개 ETF, 전부 1x 현물/금리):**
  - `KODEX 200 (069500)` — 국내주식형 1x (**일반계좌 매매차익 0% 비과세**, 금융소득종합과세 제외)
  - `KODEX 코스닥150 (229200)` — 국내주식형 1x (**일반계좌 매매차익 0% 비과세**, 금융소득종합과세 제외)
  - `KODEX KOFR금리액티브 (423160)` — 하락장 현금 대피용 (이자에만 15.4% 과세)
- **월말 정기 선정 (매월 마지막 영업일 종가):**
  1. `KODEX 200`과 `KODEX 코스닥150` 중 **① 6개월(120영업일) 총수익률 > 0%** AND **② 일간 MA100 추세 ON** 조건을 모두 통과한 지수 필터링
  2. 통과 지수 중 **6개월 모멘텀 1위 종목에 100%** 투자 (둘 다 탈락 시 `KOFR` 100% 대피)
- **월중 일간 방어 (매일 장 마감 체크):**
  - 보유 중인 지수가 `MA100`(보수형 `MA80`/`MA60` 병기)을 **3영업일 연속 하회하거나 종가 기준 -1% 이상 이탈**하면 월말을 기다리지 않고 **즉시 전량 `KOFR`로 대피** (다음 월말까지 유지)

## 🚀 로컬 실행 및 자동화

```bash
pip install -r requirements.txt
python signal_domestic_2index.py
```

- **자동 갱신:** GitHub Actions(`.github/workflows/daily-signal.yml`)가 **매주 평일 오전 08:40 KST**에 KOFIA DIS 공식 전일 종가 기준가격을 수집해 `docs/index.html`과 `docs/latest_signal.json`을 자동 업데이트·발행합니다.
- **수동 갱신:** GitHub 저장소의 `Actions` → `Daily Signal Update (Solution 1)` → `Run workflow`로 언제든 즉시 갱신할 수 있습니다.

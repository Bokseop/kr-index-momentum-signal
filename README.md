# 📈 국내 2대 지수 비과세 모멘텀 + 켈리 베팅 시그널 (해법 1)

**일반계좌 · 노레버리지(1x) · 국내 대표 지수 ETF 전용** 실전 시그널 대시보드 및 10.4년 공식 데이터 백테스트 저장소입니다.  
웹 대시보드에서 **일간 방어선(`MA100`/`MA80`/`MA60`) × 베팅 방식(`하프 켈리`/`쿼터 켈리`/`풀 켈리`/`고정 100%`) 12가지 조합**을 실시간으로 선택해 오늘의 액션, 투자금별 매수 금액·주수, 백테스트 자산곡선·낙폭(DD)·매매이력을 확인할 수 있습니다.

## 🎯 전략 구조 (해법 1 + 연속 켈리 사이징)

- **투자 대상 (3개 ETF, 전부 1x 현물/금리):**
  - `KODEX 200 (069500)` — 국내주식형 1x (**일반계좌 매매차익 0% 비과세**, 금융소득종합과세 제외)
  - `KODEX 코스닥150 (229200)` — 국내주식형 1x (**일반계좌 매매차익 0% 비과세**, 금융소득종합과세 제외)
  - `KODEX KOFR금리액티브 (423160)` — 하락장 및 켈리 잔여현금 예치용 (이자 15.4% 과세)
- **1단계 (월말 종목 선정):** 매월 말 `6개월(120일) 수익률 > 0%` AND `일간 MA 추세 ON`을 모두 통과한 지수 중 모멘텀 1위 선택 (둘 다 탈락 시 `KOFR` 100%).
- **2단계 (월중 일간 방어):** 보유 지수가 선택한 MA선을 **3영업일 연속 하회하거나 종가 기준 -1% 이상 이탈** 시 즉시 전량 `KOFR` 대피.
- **3단계 (연속 켈리 포지션 사이징, 선택):**
  - 최근 120일 연율화 초과수익률($\mu - r_f$)과 60일 연율화 분산($\sigma^2$)으로 원시 켈리 비중 $f^* = \frac{\mu - r_f}{\sigma^2}$ 산출
  - 선택 배수(`하프 0.5x` / `쿼터 0.25x` / `풀 1.0x`)를 곱해 노레버리지 `0% ~ 100%`(5% 단위) 배분, 잔여 비중은 `KOFR` 예치 (월중 ±10%p 이상 변동 시에만 리밸런싱)
